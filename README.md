# Roulette LG — APK

1. Créez un dépôt GitHub et envoyez-y tout le contenu de ce dossier
   (y compris le dossier `.github`).
2. Ouvrez l'onglet **Actions** : « Build APK » se lance seul
   (ou cliquez sur **Run workflow**).
3. Quand c'est vert (3 à 5 min), ouvrez l'exécution et téléchargez
   **roulette-lg-apk** tout en bas : décompressez-le pour obtenir `app-debug.apk`.
4. Copiez l'APK sur le téléphone et installez-le
   (autorisez « sources inconnues » si Android le demande).

Pour changer la page, modifiez `www/index.html` et faites un commit.
